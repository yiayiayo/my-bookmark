# 书签工作台使用说明

**yiayiayo 书签工作台 使用说明**

一起出发，灵感随行 —— 把常用的网站、工具与灵感，收进你的数字工作台

官网：https://www.yiayiayo.com · 版本 1.1

**重要提示：请务必定期备份配置文件**

本网站为纯前端站点，所有数据（搜索引擎、栏目、书签、主题偏好）仅保存在当前浏览器的本地缓存（localStorage）中，网站服务器不存储你的任何配置，也没有云端同步。清除浏览器缓存或网站数据、更换浏览器或设备、使用无痕（隐私）窗口，都会导致配置全部丢失且无法找回。

建议养成习惯：每次大幅整理书签后，点击右上角"⤓ 导出配置"下载 yiayiayo-config.json 备份文件并妥善保存；更换设备或浏览器时，用"⤒ 导入配置"一键恢复。

# **一、产品简介**

yiayiayo 是一个在线的个人书签导航页（起始页），在浏览器中访问 www.yiayiayo.com 即可使用，无需下载安装、无需注册账号。你可以把常用的网站整理成分类栏目，并配合多引擎搜索框，把它设为浏览器的主页或默认起始页。

主要特性如下：

- 即开即用：在线访问 www.yiayiayo.com，电脑和手机浏览器均可自适应显示；

- 多引擎搜索：内置百度、Google、必应、搜狗，可自由增删；

- 栏目分类：书签按栏目分组，支持添加、重命名、删除与拖拽排序；

- 书签卡片：支持添加、编辑、删除、跨栏目移动与拖拽排序，图标可自动获取；

- 深色 / 浅色模式：一键切换，自动记忆偏好；

- 配置导入导出：一键备份为 JSON 文件，方便迁移到其他设备；

- 数据本地保存：所有配置只存在当前浏览器的 localStorage 中，网站服务器不保存你的任何数据。

# **二、快速开始**

## **2.1 打开网站**

- 在任意现代浏览器（Chrome、Edge、Safari、Firefox 等）的地址栏输入 www.yiayiayo.com，回车即可打开；

- 手机、平板与电脑浏览器均可访问，页面会随屏幕宽度自动调整布局；

- 建议设为浏览器主页或启动页：在浏览器设置的"启动时打开"中填入 https://www.yiayiayo.com ；也可以把该网址添加到收藏夹或手机主屏幕，方便随时打开。

## **2.2 首次使用**

首次打开时，页面内置了"常用、工具、艺术"三个示例栏目和若干示例书签。你可以直接点击卡片打开网站，也可以将它们修改、删除，逐步替换成自己的内容。标题"一起出发，灵感随行。"会以打字机效果循环播放，仅为装饰动画，不影响任何功能。

# **三、搜索功能**

## **3.1 发起搜索**

在搜索框中输入关键词，按回车键（或点击右侧搜索按钮），页面会在新标签页中使用当前选中的搜索引擎打开搜索结果。

## **3.2 切换搜索引擎**

点击搜索框左侧的引擎名称（默认显示当前引擎），在弹出的下拉列表中点击目标引擎即可切换。当前选中的引擎会记忆保存，下次打开页面时自动沿用。

## **3.3 添加搜索引擎**

在下拉列表底部点击"＋ 添加搜索引擎"，填写引擎名称和搜索地址。搜索地址中必须用 %s 作为关键词占位符，例如：https://www.google.com/search?q=%s 。保存后新引擎会自动成为当前引擎。

## **3.4 删除搜索引擎**

在下拉列表中，点击某一行右侧的"×"即可删除该引擎。注意：至少需要保留一个搜索引擎，删除前会弹出确认框，防止误删。

# **四、栏目管理**

栏目是书签的分组，显示为搜索框下方的一排胶囊标签。

## **4.1 切换与添加**

- 单击栏目名：切换到该栏目，下方卡片区立即显示对应书签；

- 点击最右侧的"＋"：输入名称即可创建新栏目，创建后自动切换过去。

## **4.2 重命名与删除**

- 双击栏目名：在弹出的对话框中输入新名称即可重命名；名称不能与现有栏目重复；

- 鼠标悬停栏目：右侧会出现"×"，点击并在确认框中确认后删除。注意：删除栏目会同时删除其中的所有书签，且无法撤销；当只剩一个栏目时不允许删除。

## **4.3 调整顺序**

在桌面端（鼠标设备），直接按住某个栏目拖拽到目标位置即可调整顺序，松手后自动保存。

# **五、书签管理**

## **5.1 添加书签**

点击卡片网格末尾的"＋ 添加网站"卡片，填写网站名称和网址。网址可以省略 https:// 前缀，系统会自动补全。填写完成后点击"保存"。

## **5.2 图标显示方式**

添加或编辑书签时，可以在"图标显示"中选择三种方式：

- 自动：优先尝试获取网站 favicon，获取失败时自动改用首字图标；

- 网站图标（favicon）：始终尝试显示网站官方图标；

- 首字图标（随机背景）：用名称的第一个字（或前两个字母）生成彩色圆形图标，稳定不依赖网络。

## **5.3 打开、编辑与删除**

- 单击卡片：在新标签页打开该网站；

- 点击卡片右上角的"⋮"：展开操作菜单，可执行"打开网站 / 编辑 / 移动到其他栏目 / 删除"；

- 编辑：修改名称、网址或图标显示方式，保存后立即生效；

- 移动到其他栏目：在弹出的下拉框中选择目标栏目，书签会追加到该栏目末尾；

- 删除：删除前需二次确认，删除后不可恢复。

## **5.4 调整顺序**

在桌面端按住卡片拖拽到其他卡片的位置，即可调整同栏目内的排列顺序；拖拽经过的卡片会显示虚线框提示落点。

标题右侧的"N 个快捷入口"会实时显示当前栏目下的书签数量，随增删自动更新。

# **六、外观与主题**

## **6.1 深色 / 浅色模式**

点击页面右上角的圆形切换按钮（浅色模式下显示月亮图标 ☾，深色模式下显示太阳图标 ☀），即可在两种主题间切换。深色模式下，搜索栏、卡片、菜单、弹窗等全部界面元素都会切换为深色配色，荧光绿保留为强调色。

主题选择会保存在浏览器中，下次打开自动恢复；首次访问且没有历史选择时，会跟随操作系统的浅色 / 深色偏好。

## **6.2 打字机标题动画**

首页主标题"一起出发，灵感随行。"以打字机效果循环播放：逐字打出 → 停顿 → 逐字删除 → 重新打出，光标持续闪烁。如果你在操作系统（如 macOS 的"辅助功能 → 显示"）中开启了"减少动态效果"，页面会自动关闭该动画，直接静态显示完整标题。

# **七、配置导入与导出**

## **7.1 导出配置**

点击右上角的"⤓ 导出配置"按钮，当前的搜索引擎列表、栏目结构和全部书签会被打包成 yiayiayo\-config\.json 文件下载到本地，可用于备份或迁移。

## **7.2 导入配置**

点击右上角的"⤒ 导入配置"按钮，先在确认框中选择"选择文件"，然后挑选之前导出的 JSON 文件。页面会解析文件并显示其中包含的引擎数、栏目数和书签总数，再次确认"导入"后覆盖当前配置。

导入时请注意：

- 导入是"整体覆盖"，当前所有配置都会被文件内容替换，建议先导出备份；

- 文件必须是本网站导出的 JSON 格式，手工修改时请保持 engines、tabs 等字段结构完整，否则会提示"导入失败"；

- 非法条目（如缺少名称或网址的书签）会在导入时被自动过滤，网址会自动补全 https:// 前缀。

# **八、数据存储与隐私**

**再次强调：**本网站完全依赖浏览器本地缓存保存数据，服务器不存储任何用户配置，也没有云端同步和自动备份。防止配置丢失的唯一办法，就是定期使用"导出配置"功能手动备份，请务必重视。

所有数据（搜索引擎、栏目、书签、当前选中项、主题偏好）都保存在当前浏览器的 localStorage 中，不经过任何服务器，也没有账号体系，隐私完全由本机掌控。

需要留意的几点：

- 数据与浏览器绑定：换浏览器、换设备后数据不会自动同步，请使用"导出配置"迁移；

- 数据与域名绑定：配置只对 www.yiayiayo.com 这个网址生效。如果通过其他域名或 IP 访问本站，看到的是一份全新的空配置，同样可以用导入功能迁移；

- 清除浏览器缓存 / 网站数据会同时清除书签配置，清除前请先导出备份；

- 隐私模式（无痕窗口）中的修改在窗口关闭后不会保留。

# **九、常见问题**

**问：需要注册账号才能使用吗？**

答：不需要。打开 www.yiayiayo.com 即可直接使用，没有账号体系。相应地，你的配置只存在自己的浏览器里，别人看不到，网站也无法帮你找回——请务必自行导出备份。

**问：网站图标显示不出来怎么办？**

答：favicon 通过公共服务实时抓取，个别网站可能获取失败。可把该书签的图标显示方式改为"首字图标（随机背景）"，稳定且不依赖网络。

**问：添加搜索引擎时提示"需要包含 %s 关键词占位符"？**

答：搜索地址中必须包含 %s，网站会把它替换成你输入的关键词。例如必应的地址是 https://www.bing.com/search?q=%s 。

**问：换电脑或手机后书签还在吗？**

答：不会自动同步，因为数据只保存在浏览器本地。请在旧设备上"导出配置"，把 JSON 文件发送到新设备后"导入配置"即可完整迁移。

**问：误删了栏目或书签能恢复吗？**

答：删除操作不可撤销。建议定期使用"导出配置"做备份，误删后重新导入最近一次备份即可恢复。

**问：打字机动画可以关闭吗？**

答：动画本身常开，但页面会响应系统的"减少动态效果"辅助设置——在系统里开启该选项后，标题将静态显示。
